## РАСЧЁТЫ

```
м/с = км/ч ÷ 3,6
Путь реакции = (км/ч ÷ 3,6) × время реакции     ← ЛИНЕЙНО
Тормозной путь                                   ← КВАДРАТ
Остановочный = реакция + тормозной
```

| Скорость ×2 | ×3 | ×4 |
|---|---|---|
| тормозной **×4** | **×9** | **×16** |

| Мокро | Лёд |
|---|---|
| **×2** | **×4** |

Путь реакции при 1 с: **50→14 м, 80→22 м, 90→25 м, 100→28 м.**
Дистанция — **3 секунды**. Больше: скользко, **>80 км/ч**, тяжёлый сзади.
Зимой сцепление до **1/4**. Аквапланирование — ориентир **выше 60**.

## ОБГОН

Относительная скорость **×2 → дистанция ÷2**.
**10 км/ч → ≈500 м. 20 км/ч → ≈250 м.**
**Свободная дорога = дистанция обгона × 3.** 250 м → **750 м**.

Возврат в полосу — когда виден **передок в зеркале**.
Обгоняемый **не ускоряется**.
**Обгон на перекрёстке разрешён на приоритетной дороге**, при 2+ полосах, под светофором/полицией, справа от поворачивающего налево.
**Предупреждающая линия не запрещает** обгон. **Сплошная — лишение прав.**

## ПРИОРИТЕТ

**Полиция → светофор → знаки → правила.**
Мигающий жёлтый или погасший светофор — **выпадает**, работают знаки.

| Уступаете ВЫ |
|---|
| помеха справа |
| поворот налево, встречный справа |
| выезд с парковки, двора, тротуара |
| пересечение велодорожки и тротуара |
| **перестроение — включая тех, кто сзади** |
| поворот — пешеходам и велосипедистам прямо |
| пешеходный переход без светофора |

| **трамвай** (кроме знака уступки перед ним) |

**Регулировщик:** боком = зелёный, рука вверх = жёлтый, грудь/спина = красный.
**Зелёная стрелка = никому не уступаете.**
**Мигающий зелёный человечек = красный.**
