# Глава 10.4–10.5. Предписывающие и информационные знаки

---

# 10.4 Предписывающие знаки

**Вид группы:** круг, **синий фон**, белые символы. Могут дополняться табличкой, уточняющей, к кому относятся.

> **Правка названия группы.** В курсе они названы «обязательными знаками». Принятый термин — **предписывающие**: они не «обязывают вообще», а **предписывают направление движения или полосу**.

## Предписанное направление движения (402)

| № | Направление |
|---|---|
| **402.1** | Объезд препятствия справа |
| **402.2** | Объезд препятствия слева |
| **402.3** | Только прямо |
| **402.4** | Только направо |
| **402.5** | Только налево |
| **402.6** | Прямо или направо |
| **402.7** | Прямо или налево |
| **402.8** | Направо или налево |

## Предписанная полоса и кольцо

| № | Название | Что означает |
|---|---|---|
| **404.1** | Предписанная полоса | Объезд справа от знака |
| **404.2** | Предписанная полоса | Объезд слева от знака |
| **406** | Круговое движение | Действуют правила кольца, стрелки задают направление объезда. **Почти всегда сопровождается знаком 202 «Уступите дорогу»** |

> **Ловушка.** Знак 406 сам по себе **не обязывает уступать** — обязанность создаёт стоящий рядом знак 202. Но на практике они почти всегда вместе, и на кольцо вы въезжаете, уступив тем, кто уже на нём.

# 10.5 Информационные знаки

**Вид группы:** в основном прямоугольник, **синий фон**. Знаки порядка движения по полосам — на **белом** фоне.

## Типы дорог

| № | Название | Что означает |
|---|---|---|
| **501** | Автомагистраль | Без другого знака действует 80 км/ч, но ограничение обычно установлено. **110 км/ч — максимум на магистралях высшего класса** |
| **503** | Дорога для автомобилей | Без другого знака 80 км/ч; на отдельных участках 90 км/ч |
| **504** | Конец автомагистрали | |
| **505** | Конец дороги для автомобилей | |

> **Терминология.** В курсе 503 назван «полумагистраль» — это устаревшая калька. Действующий термин — **дорога для автомобилей** (*motortrafikkveg*). Её признаки и общие с автомагистралью запреты разобраны в главе 8.1.

## Полосы специального назначения

| № | Название | Что означает |
|---|---|---|
| **506** | Полоса для тяжёлого транспорта | Тяжёлый транспорт должен использовать эту полосу |
| **507** | Конец полосы для тяжёлого транспорта | |
| **508.1** | Полоса для автобусов | Действуют правила полос общественного транспорта |
| **508.2** | Полоса для автобусов и такси | То же |
| **509** | Полоса для транспорта с пассажирами | Только машины, где пассажиров (**включая водителя**) не меньше указанного. Автобусы и такси — независимо от числа пассажиров |
| **510.1 / 510.2** | Конец полосы общественного транспорта | |
| **511** | Конец полосы для транспорта с пассажирами | |

**Кто может ездить по автобусной полосе** (из главы 7.2): электромобили, водородные автомобили и двухколёсные — если табличка не ограничивает круг дополнительно.

## Остановки транспорта

| № | Название |
|---|---|
| **512** | Автобусная остановка |
| **513** | Трамвайная остановка |
| **514** | Стоянка такси |

**Связанное правило:** запрет остановки **ближе 20 метров** от знака остановки (глава 7.6).

## Пешеходы и велосипедисты

| № | Название | Что означает для водителя |
|---|---|---|
| **516** | Пешеходный переход | Уступать пешеходам на переходе и выходящим на него, если нет регулировщика или светофора. **Показывать намерение уступить** — обычно снижением скорости |
| **518** | Тротуар | Ездить нельзя; **при пересечении уступать пешеходам**. Останавливаться и парковаться нельзя |
| **520** | Велосипедная дорожка | Движение на автомобиле запрещено |
| **521** | Велосипедная полоса | Велополоса **справа от вас**. При перестроении уступать, следить за слепой зоной, держать интервал при обгоне |
| **522** | Пешеходно-велосипедная дорожка | Ездить нельзя; **при пересечении уступать пешеходам и велосипедистам**. Останавливаться и парковаться нельзя |

## Организация движения

| № | Название | Что означает |
|---|---|---|
| **524** | Площадка для разъезда | На длинных однополосных участках. **Парковка запрещена** |
| **526.1 / 526.6** | Одностороннее движение | Движение только по стрелке до следующего перекрёстка |
| **527.1** | Тупик | Дорога физически перекрыта |
| **527.3** | Тупик | Дорога закрыта для сквозного проезда |
| **527.4** | Тупик | Закрыта боковая дорога |
| **528** | Свободный выбор полосы | Можно двигаться по любой полосе |

## Полосы: слияние, разгон, окончание

| № | Название | Кто кому уступает |
|---|---|---|
| **530** | Слияние полос | Две полосы сливаются в одну. **Приоритета нет ни у кого** — правило молнии |
| **531** | Полоса разгона | Правая полоса объединяется с полосой разгона. **Приоритета нет ни у кого** |
| **531.2** | Полоса разгона | То же, знак сбоку от полосы разгона |
| **532** | Конец полосы | **Тот, чья полоса кончается, уступает.** Красная стрелка не сливается с чёрной — по этому и видно, кто обязан уступить |
| **534** | Начало дополнительной полосы | Дорога расширяется полосой справа; по умолчанию держитесь правой полосы |
| **536.1 / 536.2** | Съезд отдельной полосой | Обычно на съездах, образующих дополнительную полосу |
| **538** | Число полос | Показывает количество полос на проезжей части |
| **539** | Изменённая схема движения | Часто при дорожных работах |

> **Ключ ко всей подгруппе — цвет стрелки.** **Красная стрелка показывает, кто обязан уступить.** Обе стрелки красные — приоритета нет, работает правило молнии (глава 8.1).

## Жилые и пешеходные зоны

| № | Название | Что означает |
|---|---|---|
| **540** | Жилая зона | Движение **быстрее пешехода запрещено**, парковка запрещена |
| **542** | Конец жилой зоны | |
| **548** | Пешеходная улица | Движение на автомобиле запрещено. Если табличка даёт исключение — **скорость не выше пешеходной** |
| **550** | Конец пешеходной улицы | |

## Парковка и контроль

| № | Название | Что означает |
|---|---|---|
| **552** | Парковка | Парковка разрешена, если не нарушает общих правил остановки и стоянки |
| **556** | Автоматический контроль скорости | Камера фиксирует превышение |
| **556.2** | Контроль средней скорости на участке | В конце участка стоит мигающий жёлтый индикатор: мигает, если **средняя** скорость превышена |
| **558** | Видеонаблюдение | Наблюдение за движением на участке |
| **560** | Информационное табло | Разная информация о дорожной обстановке |

|---|---|---|

| **570.1** | Аварийный выход в туннеле | |

# Что запомнить к экзамену

## Цифры

| Значение | Что это |
|---|---|
| **110 км/ч** | максимум на автомагистрали (знак 501) |
| **80 км/ч** | действует на 501 и 503 без другого знака |
| **90 км/ч** | встречается на отдельных участках дороги для автомобилей |
| **20 метров** | запрет остановки от знака остановки транспорта (512–514) |
| **включая водителя** | как считаются пассажиры для знака 509 |

## Ловушки

- **Синий круг — предписание, синий прямоугольник — информация.** Форма важнее цвета.
- **406 не обязывает уступать сам по себе** — это делает знак 202 рядом с ним.
- **530/531 против 532.** При слиянии двух полос и на полосе разгона **приоритета нет ни у кого**; когда полоса **заканчивается** — уступает тот, кто в ней. Различаются по стрелкам: **красная стрелка = уступаешь ты**.
- **524 — площадка для разъезда, а не парковочный карман.** Парковаться на ней запрещено.
- **518 и 522: пересекать можно, ехать вдоль нельзя**, и при пересечении вы уступаете.
- **540 и 548 — разные зоны.** В жилой зоне запрещена парковка вне обозначенных мест; на пешеходной улице движение вообще запрещено, кроме исключений по табличке.
- **556.2 меряет среднюю скорость на участке** — сбросить скорость только у камеры не поможет.
- **Знак 501 не означает «можно 110»** — конкретное ограничение задаёт знак ограничения скорости.

## Проверено по официальным источникам

- **Термин «дорога для автомобилей»** (*motortrafikkveg*) вместо кальки «полумагистраль» — соответствует действующей терминологии Statens vegvesen; признаки такой дороги разобраны в главе 8.1.
- **Максимум 110 км/ч** — подтверждено критериями скоростных ограничений Statens vegvesen.
- **Группа 10.4 названа «предписывающие»** вместо «обязательные» — принятый перевод *påbudsskilt*.
- **Правило красной стрелки** для знаков 530/531/532 совпадает с изложенным в главе 8.1 курса.
